# Contributing

Thanks for your interest in improving this release.

1. **Issues:** Open an issue for bugs, unclear docs, or reproducibility problems (include Python version and OS).
2. **Pull requests:** Keep changes focused; run tests locally (`pip install -e ".[dev]" && pytest`) before submitting.
3. **Privacy:** Do not commit participant identifiers, ages, sex, or institution-specific paths—use environment variables and local-only CSVs as documented in `docs/data_layout.md`.
